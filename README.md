# ZamoPi Privacy Policies

Halaman kebijakan privasi untuk aplikasi ZamoPi, disiapkan untuk GitHub Pages.

- Halaman awal: `index.html`
- Hello Banyuwangi (ID): `hello-banyuwangi/index.html`
- Hello Banyuwangi (EN): `hello-banyuwangi/en.html`
- Style bersama: `assets/style.css`

Aktifkan GitHub Pages dari **Settings → Pages → Deploy from a branch → main / (root)**.
